AI 智能生成表单 ​

form-cook 内置了 AI 生成表单能力，你只需用自然语言描述想要的表单，即可自动生成对应的表单 Schema，预览确认后一键应用到画布。

功能入口 ​

打开设计器后，点击顶部工具栏左侧的 AI 按钮，即可打开「AI 生成表单」弹窗。

使用流程 ​

  1. 在左侧输入框中描述你想生成的表单需求，例如：
    • 生成一个员工入职表单，包含姓名、手机号、部门、职位、入职日期、紧急联系人
    • 帮我做一个活动报名表，需要姓名、手机号、邮箱、公司、参与场次、备注
    • 生成一个请假申请表，包含申请人、部门、请假类型、开始日期、结束日期、请假事由、审批人
  2. 点击「生成表单」按钮，等待生成完成。
  3. 在右侧「生成结果预览」中查看生成的 Schema 结构与摘要说明。
  4. 确认无误后点击「应用到画布」，即可将生成的表单替换到当前画布。

TIP

弹窗内置了若干示例提示词，点击标签可快速填入输入框，方便体验。

两种生成模式 ​

AI 生成支持两种模式，可在弹窗右侧的「模型配置」中切换：

本地规则模式（默认） ​

无需配置任何模型或密钥，开箱即用。适合先体验完整流程，或在没有大模型服务时使用。

  • 优点：零配置、响应快、稳定不依赖网络
  • 局限：基于内置的字段词库与场景模板生成，理解能力有限，复杂需求建议使用大模型模式

OpenAI 兼容接口模式 ​

连接你自己的大模型服务，生成能力更强、更灵活。

安全提示

API Key 默认仅保存在当前浏览器的 localStorage 中。默认情况下不会保存 API Key，需要手动勾选「记住 API Key 到本地浏览器」才会持久化。请勿在公共设备上保存密钥。

配置大模型 ​

  1. 切换到「OpenAI 兼容接口」模式。
  2. 选择服务商预设（或选择「自定义」后手动填写）。
  3. 填写或确认 Base URL、模型名称、API Key。
  4. 可选：调整 Temperature（0 ~ 1，越低越稳定）。
  5. 配置完成后即可在输入框中描述需求并生成。

INFO

配置会自动保存到本地浏览器。切换服务商预设时，Base URL 和 模型名称 会自动填充为该服务商的默认值。

生成结果说明 ​

生成结果包含三个部分：

  • 摘要（summary）：对本次生成的简短说明，例如生成了多少个字段、基于什么场景。
  • 警告（warnings）：需要你留意的提示，例如当前使用的是本地规则、字段校验需要继续细化等。
  • Schema 预览：完整的表单 JSON 结构，采用只读代码编辑器展示，方便核对。

注意事项 ​

  • 应用到画布时会替换当前画布内容，建议先保存当前表单再使用 AI 生成。
  • 大模型返回的字段校验规则、远程数据源、复杂联动等可能需要你在右侧配置面板中继续细化。
  • 使用 OpenAI 兼容接口模式时，请确保你的网络可以访问所配置的 Base URL。
